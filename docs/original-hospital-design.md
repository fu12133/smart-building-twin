# 原创现代医院外观方案

本方案按用户2026-10-14“自己做一个，参考现代医院”的要求，在项目白模体量上进行原创美术深化，未采购或复制图库医院模型。

## 可检查的成品

- 真实三维细节：沿源立面剪裁的金属幕墙框、珠白层间带、遮阳翼、细部灯带，以及一处带支撑/玻璃顶的门厅雨棚。
- 原创材质：蓝灰玻璃的物理反射与清漆、不同楼层的窗口/窗内层次、粗糙度贴图，以及珠白面板接缝。窗贴图1024×2048，面板1024×1024；不是宣称8K或照片级模型。
- “图层设置 → 原创医院方案”默认开启；关闭回看既有源形体与材质方案。切换不重置相机、不替换周边和场地、不更改分区/楼层。
- 名称未指定，保持通用医疗符号。新增门厅/幕墙是设计建议，不是已核实的医院立面或竣工模型；室内仍是28种未核实示意布局。

## 来源和制作

`src/hospitalDesign.ts`从源网格三角形形成墙面，网格线在墙面内求交、合并区间后生成实例化构件，保留裙房中庭与源侧后轮廓。所有新增构件共用单元几何并按分区/材质合批。纹理由项目确定性绘制，玻璃反射随Three.js相机与环境光变化。

原主体/周边GLB不变；照明及共享坐标基准仅使用源包围盒。方案材质与源材质分别持有，销毁前恢复源材质引用，以确保隐藏资源也被释放。BuildingScene仍管理唯一相机、渲染器、输入、阴影、天气和销毁，不增加持续动画。

实际验收结果和截图见`docs/verification.md`。对模型质量的审美满意度需客户看实际版本判断，交互测试通过不代替客户视觉认可。
