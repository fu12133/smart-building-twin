# 设计

在现有SceneAtmosphere提升等距柱状天空纹理分辨率，绘制有清晰亮核和多层径向衰减的太阳，保持随相机旋转的无限远天空和源几何遮挡。以现有深圳日出日落/北京时间阶段近似太阳方向，主DirectionalLight使用相同方向与暖色温；阴天抑制直射，地面和玻璃沿用现有光照/阴影/反射管线。无额外逐帧后处理，无修改主体或周边GLB。

新增sunPreview状态和用户控件，不修改真实天气对象或时间。晴天预览使用固定的展示日照阶段及晴空，场景明确标“晴天日照预览 · 非实时天气”；天气卡片仍为真实来源，取消后恢复实时。开关保持相机/层/设备/楼层状态；室内不显示太阳且保持原楼层照明，返回外景恢复选择。天气效果关闭时恢复既有夜景展示预设且暂停太阳预览。天空与PMREM由SceneAtmosphere持有、更新时释放、销毁时完整dispose；只在分钟/天气/开关变化时更新，按日照阶段量化避免持续空闲GPU刷新。

采用低仰角、正面天空的固定晴天展示方向方便在默认俯视中发现太阳；实时方向仅是展示近似，不能声称真北、实测太阳位置或医院日照分析。实际截图决定圆盘/光晕大小、亮度与是否遮挡主体。
完整页面重新加载回到默认深圳实时模式，不持久化晴天预览，避免下次访问误认展示天气。
附加显式“观察太阳”相机按钮，抬高观察天空并对准当前太阳方向；只有点击此按钮才改变视角，预览开关本身保留姿态。沿用OrbitControls边界、距离与复位功能。

云端软件GPU保留2048×1024天空绘制源，但显式将背景Cube转换限制为512面、反射预过滤输入限制为1024×512；硬件GPU继续使用完整2K输入。新增背景RenderTarget由SceneAtmosphere更新/销毁释放，临时反射纹理在预过滤完成后dispose。既有多次往返/旋转/截图压力测试的CI总预算对齐180秒（与既有天气多阶段用例一致），所有功能/相机/资源断言保留，旋转后等待渲染就绪再截图。
