# Design
## Verified source
The original DWG was recovered from the existing WeChat long-term file directory and matches the recorded SHA256. The original decoded JSON remains available. Mesh263 contains 2133 disconnected urban components and no hospital replacement at the origin. Mesh575 contains32 nearby components. Site meshes249–260,392–395,562,580 include colored planar divisions, broad ground and detailed local site. These20 handles will be converted. Other handles are overlapping hospital fragments, displaced editing copies or unrelated editing planes; they are not mechanically imported as surroundings.

## Geometry and materials
Package a separate project-context.glb and project-context.json with original/decoded hashes, per-handle roles/bounds/counts, coordinate transform[x,z,-y] and the shared hospital scale/anchor. Do not independently recenter the context. User additionally requires the hospital itself to match the source. Preserve the source hospital geometry and remove unsupported procedural facade members, entrance signs/forecourt and landscape footprints. The current69.5/205 calibration conflicts with DWG header meter units; a clarification is pending between project69.5m calibration and raw source dimensions. Finishes remain proposed because actual material references are unavailable. Flat/concave polygons use robust ear clipping with duplicate/collinear handling, not fan fills that close source openings. Record skipped degenerates and exact duplicate faces. City and ground carry source handles, no hospital-building IDs.

## Runtime
A dedicated asset owns context building/ground groups and their resources. BuildingScene attaches buildings to the existing surroundings layer and source site separately to the city. Remove procedural context, ground, forecourt/signs, landscaping and added hospital facade geometry so exterior shape matches the selected source model. UI selection/device indicators remain overlay data, not architecture. Do not load unused foliage textures. Include context readiness in asset readiness; expose readable loading/failure state. Dispose loaded/replaced resources and release late completion without attaching to an obsolete scene.

## Camera and interaction
Default framing retains the hospital view. A full-white-model control fits the complete source bounds in the actual unobstructed canvas region, expands viewing limits and reduces fog for distant geometry. Reset restores default framing/fog. Floor entry/exit preserves the exact saved exterior pose and full-view state. Source context blocks picking through foreground buildings but cannot select hospital A/B; hidden surroundings do not intercept hits. Existing layers, floor scope and equipment selection remain unchanged.

## Validation
Strict specs/build/full harness plus repository-path and public production smoke tests. Verify context hashes/roles/transforms and primary GLB unchanged; actual full-view pixels, layer toggling, nonselectable surroundings and exact floor roundtrip. Delay/reload context loading and inject asset failure to check lifecycle and recovery. Inspect default/reverse/full-scene and mobile screenshots, update actual evidence, publish and archive.
