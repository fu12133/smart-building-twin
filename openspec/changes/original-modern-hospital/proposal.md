# 原创现代医院外观方案

## Why
客户不满意白模材质效果，用户明确要求自行制作参考现代医院的原创模型。需要在项目体量上深化可旋转的美术细节，并能够回看原白模。

## What Changes
- 默认展示原创医院外观：贴合源立面的真实幕墙框、遮阳构件、层间带、细部灯带及一处门厅雨棚设计。
- 珠白面板、蓝灰玻璃、窗内层次与精细接缝；所有纹理及新增几何由项目原创生成，无付费素材依赖。
- 增加“原创医院方案”图层开关，关闭后显示原白模及既有材质方案；不改源主体和周边资产、统一比例、位置或楼层平面。
- 明确新增造型为设计方案，不声称已核实医院、现场尺寸或BIM；不写医院名称。
